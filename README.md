### EnergyCast - Machine Learning

I used Python to analyze historical natural gas prices, build seven features from published observations, and compare Linear Regression and Random Forest against a simple persistence baseline. I evaluated the models using chronological validation and test sets, and the baseline achieved the lowest test error. The project includes the source data, code, prediction results, and execution evidence.

[View the EnergyCast project](https://github.com/juliusdtillman/EnergyCast-Machine-Learning)
